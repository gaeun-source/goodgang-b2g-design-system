# 굳갱랩스 B2G 디자인 시스템

검토 중인 디자인 시스템입니다. 완성·승인된 제품 명세가 아닙니다.

## 편집과 미리보기

빌드 없이 사용하는 HTML/CSS/JavaScript 사이트입니다. `docs/`가 웹 루트이며 GitHub Pages는 main 브랜치의 docs 폴더를 게시합니다.

```sh
python3 -m http.server 8000 --directory docs
```

브라우저에서 http://localhost:8000 을 엽니다.

- `docs/index.html`: 문서 화면과 구조
- `docs/style.css`, `docs/components.css`: 스타일 및 컴포넌트 미리보기
- `docs/app.js`: 팔레트 편집기와 상호작용
- `docs/design-system.json`: 기계가 읽는 규칙과 토큰
- `docs/guide.md`: 디자인 가이드
- `docs/project-theme.json`: 프로젝트 테마
- `docs/llms.txt`: AI가 참고할 시작점

## 협업 규칙

조가은 디자이너와 조가은이 사용하는 에이전트만 수정합니다. 클로드가 이 저장소에 쓰려면 소유자 계정으로 승인된 GitHub 연결이나 로컬 체크아웃이 필요합니다. 공개 열람 권한은 쓰기 권한과 다릅니다.

사용자가 확정한 값과 검토용 예시는 구분하고, 값을 임의로 재설계하지 않습니다. 화면·가이드·JSON의 규칙은 함께 갱신합니다.

- 기본 자간은 −2% (`-0.02em`), −2px가 아닙니다. Figma에서는 변수 연결 없이 텍스트 스타일에 직접 입력합니다.
- 말풍선 자간은 별도 예외 −0.4px입니다.
- Main/Sub/Neutral 팔레트 → 역할 → 컴포넌트 순서로 컬러를 연결합니다.
- 콘텐츠 줄글은 남은 너비를 채우고, 내용에 맞춰 높이가 늘어나도록 합니다.
- 실제 모바일 검토 기준은 393×660 웹 콘텐츠 영역입니다. iPhone Safari 상하단 배경과 안전 영역도 확인합니다.
- 브라우저에 저장된 팔레트 편집값은 브라우저별 localStorage 값입니다. 기본 테마를 영구 변경하려면 소스를 수정해야 합니다.

이 저장소는 공개된 사이트 소스를 옮긴 것입니다. Figma에서만 수정한 내용은 자동 동기화되지 않습니다.
