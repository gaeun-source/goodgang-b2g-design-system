# 캐릭터 이미지 생성 [확정, 가은 11/04]

> 프로젝트 캐릭터의 3D 이미지 4장(서 있기, 인사, 프로필, 대기 화면 배경)을 만드는 AI 작업 기준. 이 문서를 읽은 AI는 아래 순서대로 직접 생성한다.

## 만드는 이미지

| 파일 | 쓰는 곳 | 형식 |
|---|---|---|
| `{이름}-stand.png` | 아바타 화면, 대기 화면 이미지 | 전신, 두 손을 배 앞에 모음. 배경 투명, 세로 약 1:2 |
| `{이름}-hello.png` | 아바타 인사, 빈 화면, [OG 이미지](og-images.md) | 전신, 한 손 들어 인사. stand와 같은 크기·위치 |
| `{이름}-profile.png` | 아바타 말풍선 프로필(지름 28px 원), 파비콘 | 머리만 정면, 정사각형, 배경 투명 |
| `{이름}-entry.jpg` | 대기 화면 배경 | 세로 9:16, 1440×2560 |

## 참조 그림 (이 사이트에 있음, 항상 같이 넣음)

스타일 참조는 생김새가 다른 두 캐릭터를 함께 준다. 같은 질감의 다른 생김새를 보여 줘야 모델이 생김새가 아니라 질감만 따른다.

| 파일 | 내용 |
|---|---|
| [style-bandali-stand.png](character/refs/style-bandali-stand.png), [style-bandali-hello.png](character/refs/style-bandali-hello.png) | 반달이(곰) 서 있기·인사 |
| [style-dori-stand.png](character/refs/style-dori-stand.png), [style-dori-hello.png](character/refs/style-dori-hello.png) | 도리(감 모자) 서 있기·인사 |
| [style-dori-profile.png](character/refs/style-dori-profile.png) | 프로필 구도 예시 |
| [style-bandali-entry.jpg](character/refs/style-bandali-entry.jpg), [style-dori-entry.jpg](character/refs/style-dori-entry.jpg) | 대기 화면 구도·배경 톤 예시 |
| [example-dori-original.png](character/refs/example-dori-original.png) | 프로젝트가 주는 캐릭터 원본의 예(도리 2D). 스타일 참조로 쓰지 않음 |

## 작업 순서

1. **입력 확인.** 사용자에게 받을 것은 아래뿐이다. 빠진 것만 묻는다.
   - 프로젝트(기관·지역)와 캐릭터 이름
   - 캐릭터 원본 그림 1장 이상(2D 일러스트, 사진, 기존 3D 무엇이든). 없으면 생김새 설명을 받는다.
   - 대기 화면 배경 소재와 톤. 없으면 지역의 대표 풍경과 캐릭터 대표 색의 연한 파스텔로 정하고 사용자에게 알린다.
2. **서 있기 1장을 먼저 만든다.** 공통 프롬프트 + 아바타 프롬프트의 1)만. 결과를 사용자에게 보여 주고 확정받는다. 생김새가 원본과 다르면 여기서 다시 만든다.
3. **확정한 서 있기를 원본으로 나머지 3장을 만든다.** 이때는 `캐릭터 원본`에 확정한 stand를 넣는다. 네 장이 같은 캐릭터로 보이게 하기 위해서다.
4. **후처리와 반영.** 아래 「받은 뒤 할 일」.

이미지 도구는 정하지 않는다(도리는 GPT Image 2로 만듦). 참조 그림 여러 장을 받을 수 있는 도구를 쓴다.

## 프롬프트

`{ }`만 채운다. 공통 블록 뒤에 해당 이미지 블록을 붙인다.

### 공통 (항상 맨 앞)

```
{기관·지역} 캐릭터 '{이름}'의 3D 이미지를 만들어 줘. 아래 참조 그림을 먼저 보고 써 줘.
- 캐릭터 원본: {원본 그림} — {생김새: 머리·몸 모양, 대표 색, 눈·눈썹·볼·입, 소품}
- 3D 스타일 참조: style-bandali-stand.png, style-bandali-hello.png, style-dori-stand.png, style-dori-hello.png.
  두 캐릭터는 생김새가 다르지만 질감·조명·렌더가 같다. 이 공통점만 따르고 생김새는 따르지 않음.

캐릭터의 생김새·비율·색은 원본 그대로. 재질과 조명만 참조처럼 부드러운 펠트·플러시 질감의 3D 렌더로.
밝고 고른 스튜디오 조명, 정면을 봄. 글자·로고·워터마크 넣지 않기.
모든 이미지에서 같은 캐릭터로 보이게 얼굴·색·비율을 똑같이 유지.
```

원본이 없으면 `캐릭터 원본` 줄에 생김새 설명만 적는다.

### 아바타 (서 있기 · 인사)

```
1) {이름}-stand.png: 전신, 정면으로 서서 두 손을 배 앞에 모은 자세.
2) {이름}-hello.png: 전신, 한 손을 어깨 높이로 들어 인사하는 자세. stand와 같은 크기·같은 위치.
둘 다: 배경 투명, 바닥 그림자 없음, 세로 1:2, 캐릭터는 가로 가운데, 머리 끝과 발끝이 위아래 가장자리에 거의 닿게.
```

### 프로필

참조에 `style-dori-profile.png`를 더한다.

```
3) {이름}-profile.png: 얼굴(머리)만 정면 클로즈업, 몸 없음. 정사각형, 배경 투명.
머리가 가로·세로의 약 90%를 채우고 가운데(style-dori-profile.png와 같은 구도).
지름 28px 원으로 줄여도 눈·입이 보이게 표정은 단순하게.
```

### 대기 화면 배경

참조에 `style-bandali-entry.jpg`, `style-dori-entry.jpg`를 더한다.

```
4) {이름}-entry.jpg: 세로 9:16(1440×2560). 캐릭터가 앉거나 서서 한 손 들고 인사, 가로 가운데, 세로 중간보다 조금 아래.
구도와 배경의 흐린 정도는 style-bandali-entry.jpg, style-dori-entry.jpg와 같게.
위쪽 1/3은 이름·안내 문구, 아래쪽 1/4은 버튼이 올라가니 하늘·땅처럼 단순하게 비워 둠.
배경은 {지역 소재, 예: 상주의 감나무 과수원과 낮은 언덕}을 아주 연하고 흐릿하게, {톤, 예: 크림·복숭아} 파스텔로.
배경이 캐릭터보다 눈에 띄지 않게. 그림자는 캐릭터 발밑에만 아주 연하게.
```

## 받은 뒤 할 일

- **아바타 두 장:** 투명 여백을 잘라 쓴다(도리 535×1060, 559×1060).
- **프로필:** 240px 정사각형으로 줄인다. 화면에서는 원 안에 꽉 차게(`object-fit: cover`) 넣는다. 반달이 전용 자르기 값을 쓰지 않는다.
- **파비콘 [가은 11/04]:** 프로필 이미지로 만든다. `favicon-32.png`는 32×32 투명 배경. `apple-touch-icon.png`는 180×180, 페이지 위쪽 배경색(`bg-page-top`, main-100) 위에 머리 150px를 가운데. iOS는 투명 부분을 검게 칠하기 때문이다.
- **배경:** JPG 1440×2560으로 저장한다. 대기 화면은 캐릭터 영역을 기준으로 맞추므로 캐릭터가 차지하는 상자 좌표를 재서 구현에 넘긴다.
- **설정:** 파일 경로를 [project-theme.json](project-theme.json)에 적는다. 프로필은 `bubbleAvatar.image`, 나머지는 `characterImages`.
- **팔레트:** 캐릭터 대표 색으로 main, 보조 색으로 sub를 만들고 gray는 main 색조를 따른다([컬러와 테마](guide.md)). 수치는 사용자 확인 전 확정하지 않는다.
- **검수:** 네 장을 나란히 놓고 같은 캐릭터인지, 원본과 생김새가 같은지 확인한다. 다르면 2단계부터 다시.

## 금지

- 반달이·도리의 생김새를 새 캐릭터에 섞지 않는다.
- 참조 그림을 그대로 프로젝트 이미지로 쓰지 않는다.
- 캐릭터 원본이 없는데 생김새를 AI가 지어내 확정하지 않는다. 서 있기 1장을 보여 주고 확정받는다.
